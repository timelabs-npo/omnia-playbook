# TIMELABS_AGENT_AGENCY_NEIGHBOURS

## Agency primitives and neighbours

| Timelabs concern | Neighbour family | Relevance |
|---|---|---|
| Multi-agent disagreement handling | formal argumentation / belief revision / adjudication protocols | Provides explicit semantics for unresolved conflict and admissibility. |
| Owner intent pre-failure | safety case + mission assurance doctrine | Encodes intent before incidents to avoid ad-hoc authority inflation. |
| Bounded delegated action | capability-based security / object-capability models | Delegation by explicit authority tokens and revocable scope. |
| Tribunal input vs runtime authority | supervisory control architectures | Separates recommendation engines from final actuation authority. |
| Read-only → replay → bounded mutation | shadow mode, canary, transactional infra | Allows reversible progression from observation to intervention. |
| Agent memory is not truth | event provenance + authoritative source models | Distinguishes cached inference from canonical evidence. |

## Distinctions to preserve
- Recommendation channel must remain non-authoritative by default.
- Majority alignment is insufficient for mutation authorization.
- Any resolved action must reference concrete evidence IDs and authority scope.
