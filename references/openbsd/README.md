# OpenBSD References

Store links and notes to OpenBSD documentation used by adapters and playbooks.

Suggested primary references:

- `afterboot(8)` for post-install system checklist
- `hostname.if(5)` for interface configuration files
- `pf.conf(5)` and `pfctl(8)` for packet filter syntax and validation
- `rcctl(8)` for service state inspection
- `resolv.conf(5)`, `unwind(8)`, and `unbound(8)` for DNS behavior
- `iked(8)`, `ipsec.conf(5)`, `bgpd(8)`, and `relayd(8)` when those services are in scope
