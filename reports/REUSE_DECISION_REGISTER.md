# Reuse Decision Register — Timelabs Networking Primitive Categorisations

> **Gate**: MANDATORY NETWORK PRIOR-ART / SEMANTIC-NEIGHBOUR GATE. Output companion to [SEMANTIC_NEIGHBOURS_MATRIX.md](SEMANTIC_NEIGHBOURS_MATRIX.md).
> **Acceptance Rule**: ONLY categorisations in this register are eligible for Omnia/MBSD/Blueshoes networking design actions. No other networking primitive may be proposed, renamed, extended, or implemented until this register is updated with evidence.
> **Categorisations** (exactly 4 + 1 meta; per-gate requirements):
> 1. **REUSE_DIRECTLY** — Existing implementation used unchanged; Timelabs writes no new protocol/mechanism code; only configuration and evidence collection adapters.
> 2. **WRAP_AS_PROVIDER** — Existing implementation preserved as-is behind an Omnia normative *typed provider contract* (thin wrapper, zero semantic modification of existing implementation behaviour per project memory: "thin typed contract over existing implementations" rule).
> 3. **PRIOR_ART_ONLY** — Design lessons, algorithms, or architectural patterns only are extracted; no reuse of implementation code or wire format; component does NOT become Omnia ontology default.
> 4. **GENUINELY_UNSOLVED** — Only items in this category are ELIGIBLE for new Timelabs protocol/mechanism design post-gate. Per-gate rule: "Only the last category is eligible for new protocol or mechanism design."
> 5. **META: GATE_CLOSURE** — Summary of gate compliance status and unsolved eligibility rules.
