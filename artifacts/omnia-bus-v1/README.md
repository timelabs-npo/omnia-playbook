# Omnia bus ABI 1.0 fixtures

`omnia-dns-macos.omnb` is the positive golden compiled from four DNS YAML documents and `bus/fixtures/dns-macos.bundle.json`. The other binaries are deterministic adversarial fixtures for boundary, contradiction, truncation, missing provenance, and unsupported-version handling. `manifest.json` and `SHA256SUMS` are regenerated by `make compile-bus`.

Measured input/output size for the golden fixture:

| Surface | Bytes | Relative to output |
| --- | ---: | ---: |
| Four source YAML documents alone | 1,832 | output is 600 bytes / 32.75% larger |
| Assurance/provenance source JSON | 2,543 | — |
| Full semantic input (YAML + assurance JSON) | 4,375 | — |
| Compact ABI binary | 2,432 | 1,943 bytes / 44.41% smaller than full input |

The binary is not claimed to be smaller than the YAML alone: it additionally contains the required assurance states, freshness, evidence IDs, full provenance IDs, integrity hashes, target, and versioned framing.
